### 技术要点（重要，可复用）
- **构建命令**：`"C:/Ruby33-x64/bin/bundle.bat" exec jekyll build`（jekyll 4.4.1 / jekyll-scholar 7.1.3 / ruby 3.3.7，实测可用）。
  ⚠️ **不要用 `ruby -S jekyll`**，会撞 bundler 的 rake 版本冲突（`activated rake 13.4.2, but Gemfile requires 13.2.1`）。此前 2026-09-09 记录称本机 Jekyll 不可用，**该结论有误，已修正**。
- **kramdown smart_quotes 陷阱**：正文中写 ASCII 直引号 `"`，若前后都是汉字，kramdown 会把开引号也判成右引号（渲染成 `关于”生态水动力学”`）。
  → 中文正文必须直接写正式引号 `“ ”`（U+201C/U+201D）。本次已修正 home/interests/openings/publications 中的该问题。
- `parse_block_html: true` 生效：`<div class="intro-box">` 内可用 markdown（`**粗体**`、空行分段均正常渲染为 `<p>`）。
- **`.jekyll-metadata` 被 git 跟踪**（未 gitignore）。`jekyll build`（incremental:false）会删除它；构建后需 `git checkout -- .jekyll-metadata` 恢复，避免引入无关改动。
- 站点为深色主题（body `#222` + 白字），自定义色变量在 `_sass/bootstrap.scss:46` 起（`--caugreen: #00873c` 等）。预览时用 `python -m http.server` 于 `_site` 起静态服务即可（不触碰工作区）。
- 布局：`homelay` 为 col-sm-7 正文 + col-sm-5 内嵌 sidebar（注意正文宽度较窄）。
